Roadmap

The course mirrors the `ai-coding-agents-for-everyone` architecture: chapters grouped into modules, each ending with exercises, a practice bank, interview prep, a project, and a builder thought-process journal. Hands-on chapters that need a real model run against Ollama by default — zero API cost, zero API key — with a documented option to swap in a hosted provider instead.

Module 1: Threat Modeling LLM Systems

A structured way to think about LLM attack surface before diving into any specific attack.

Outcome: map an LLM system's attack surface using the OWASP Top 10 for LLM Applications.

Module 2: Prompt Injection Deep Dive

The single most consequential LLM-specific vulnerability class, covered in real depth.

Outcome: construct and defend against realistic direct/indirect injection and jailbreak techniques.

Module 3: Data & Model Integrity

Attacks on the model and its training/deployment pipeline, not just its runtime inputs.

Outcome: explain data poisoning, model extraction, and supply-chain risk mechanically.

Module 4: Securing RAG & Agentic Systems

Applying this course's depth to the two system shapes most real LLM products actually take.

Outcome: secure a RAG pipeline and an agent's tool layer against adversarial input.

Module 5: Red-Teaming & Output Handling

The practitioner half: running a real red-team exercise and handling output safely.

Outcome: run a structured red-team exercise and produce a real findings report.

Module 6: Capstone

Design and defend a security architecture for a realistic LLM system.

Outcome: think and design like a security architect, not just a practitioner.
