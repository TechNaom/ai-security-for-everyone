Chapter 5 Exercises ~40 min, hands-on

Exercises: Evaluating Prompt-Injection Defenses Honestly

These exercises use a new scenario, deliberately different from the lesson's Harborview Claims example: Fernbridge Freight, a fictional logistics-coordination assistant with a RAG-indexed route/policy library, a carrier-tracking tool, a customs-page summarizer, and one tool with a real side effect, authorize_reroute(shipment_id, new_route, extra_cost). You'll classify defenses by category, compute real evaluation metrics from raw counts, judge whether adversarial iteration was genuinely satisfied, and critique flawed evaluation reports for metric/category mismatches.

Exercise standard Eight tasks total. Four are marked production-gear — real metric computation from raw counts, adversarial-iteration judgment, critiquing flawed evaluation reports, and research citation matching — not just concept recall.
How to run these Download starter.py, fill in every # TODO, then run python3 starter.py to see an automated score report. Compare against solution.py, which scores a perfect 23/23.

1 Classify defenses by category

Sort six defenses named across Chapters 3–4 into the correct one of this chapter's three categories — structural, detection, or consequence-bounding.

2 Production-gear Compute real metrics

Given raw blocked/succeeded/false-positive counts from a real corpus run, compute the actual block rate and false-positive rate as percentages — real arithmetic, not a description.

3 Honest practice vs. the single-attempt trap

For four described evaluation approaches, decide which are real, honest evaluation practice and which fall into the single-attempt trap or an overclaimed conclusion.

4 Production-gear Adversarial-iteration judgment

Given three scenarios, decide whether Step 4 (adversarial iteration) was genuinely satisfied or still needs to be run.

5 Match category to evaluation question

Map each of the three defense categories to its correct real evaluation question.

6 Production-gear Critique flawed evaluation reports

Given four report excerpts, decide which contain a real metric/category mismatch and which are sound.

7 Production-gear Research citation matching

Match three real, published-research descriptions to their actual source — OpenAI's Instruction Hierarchy paper, Anthropic's guardrails documentation, or the sandwich-prompting adaptive-attack research.

8 Production-gear Written reasoning

Write a real, justified sentence explaining why a 0% measured success rate against a static corpus isn't proof a defense eliminates the risk.
