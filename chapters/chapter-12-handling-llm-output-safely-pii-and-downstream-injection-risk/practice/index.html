Chapter 12 Practice Bank ~30 min, hands-on

Practice Bank: Handling LLM Output Safely: PII and Downstream Injection Risk

Eight short, independent scenarios, each with its own fictional organization — none of them Fenwick Customer Experience (the lesson) or Thornbury HR Cloud (the exercises). The first six drill fast, accurate classification of which of this chapter's six failure shapes a given event belongs to; the last two test real judgment about what actually makes an output-handling defense sufficient.

Why this bank leans on judgment, not recall Deciding whether an output-handling defense is actually sufficient is a judgment skill, not a lookup — a system with some real controls in place can still have one specific, actively exploitable gap. Scenarios 7-8 have no single keyword to pattern-match against; you have to reason about which control is missing and what its absence actually costs.
How to run these Download starter.py, fill in every # TODO, then run python3 starter.py to see an automated score report. Compare against solution.py, which scores a perfect 8/8.
