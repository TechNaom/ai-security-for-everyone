Chapter 11 Project ~90 min, hands-on

Project: Red-Team Engagement Against Ledger Copilot

Module 5's own new deliverable shape — per the curriculum map, "a full red-team exercise against a provided target, with a real findings report," assessed by "a red-team report graded against a rubric," not a find-and-fix lab like Chapters 9-10's.

The target starter.py ships a complete, runnable, intentionally vulnerable version of Ledger Copilot, Alderglen Financial's internal assistant — a fresh, self-contained target with three planted vulnerabilities mirroring three techniques this course already taught: indirect prompt injection via a wiki chunk (Chapter 4/9), adversarial tool output via an account note (Chapter 10), and system-prompt flag leakage (Chapter 3).
What you do Run the target as-is, then implement Phase 3 (execute and record), Phase 4 (classify severity), and Phase 5 (write the findings report) — Phase 1 (scope) and Phase 2 (test-case design) are already provided in starter.py. Grade your finished report against RUBRIC.md's five criteria.
starter.py solution.py (reference) RUBRIC.md README.md (full brief)

1 Run the raw target

python3 starter.py demonstrates all three vulnerabilities against the deterministic target with zero edits needed.

2 Implement Phase 3 — execution and documentation

Fill in run_test_case() to call the target and record the real observed result for each test case.

3 Implement Phase 4 — severity classification

Fill in classify_severity() using the same likelihood-times-impact rubric as the exercises.

4 Implement Phase 5 — the findings report

Fill in write_finding_report_entry() with real reproduction steps, evidence, severity, and a recommended fix pointing back to the correct chapter's real defense.

5 Complete and self-grade the report

Add an executive summary and severity-ordered remediation list, then grade the finished report against RUBRIC.md's five criteria (target: 18-20/20).

See README.md for the full brief and RUBRIC.md for the complete grading rubric.
