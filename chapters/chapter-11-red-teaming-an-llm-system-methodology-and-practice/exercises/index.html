Chapter 11 Exercises ~40 min, hands-on

Exercises: Red-Teaming an LLM System: Methodology and Practice

These exercises use a new scenario, deliberately different from the lesson's Alderglen Financial example: Corvette Bay Utilities, a fictional regional electric utility whose Outage Assistant helps call-center staff answer outage questions, retrieving from an internal wiki and calling a partner smart-meter vendor's diagnostic tool. You'll classify process events by phase, compute a real severity rating, judge honest claims versus overclaims, map system features to OWASP categories, order findings by severity, critique flawed report excerpts, and match real research findings to their actual published source.

Exercise standard Eight tasks total. Five are marked production-gear — real severity- rating computation, feature-to-category mapping, ordering findings by severity, critiquing flawed reports, and research citation matching — not just concept recall.
How to run these Download starter.py, fill in every # TODO, then run python3 starter.py to see an automated score report. Compare against solution.py, which scores a perfect 26/26.
starter.py solution.py (reference)

1 Classify events by red-teaming phase

Sort six process events into scoping, test design, execution, classification, or reporting.

2 Production-gear Compute a real severity rating

Given a likelihood and impact score, compute a combined severity rating using this chapter's own formula — real arithmetic, not a guess.

3 Honest claim vs. overclaim/process gap

For four described statements, decide which reflect sound red-team process and which contain a real gap.

4 Production-gear Map feature to OWASP category

Given four Outage Assistant features, name the single best-fit OWASP Top 10 category.

5 Production-gear Order findings by severity

Given four findings' likelihood/impact pairs, order them from highest to lowest combined severity.

6 Production-gear Critique flawed report excerpts

Given four report excerpts, decide which contain a real reasoning gap and which are sound.

7 Production-gear Research source matching

Match four real, published findings to their actual source — OWASP's GenAI Red Teaming Guide, NIST's Generative AI Profile, Microsoft's 100-products lessons, or OpenAI's external red-teaming approach.

8 Written reasoning

Write a real, justified sentence explaining why Phase 5's report can only be as good as Phases 1-4 that precede it.
