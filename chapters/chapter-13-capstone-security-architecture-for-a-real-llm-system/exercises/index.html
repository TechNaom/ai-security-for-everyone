Chapter 13 Exercises — Capstone ~45 min, hands-on

Exercises: Capstone: Security Architecture for a Real LLM System

These exercises use a new scenario, deliberately different from the lesson's Cinderpeak Systems example: Grantham Municipal Services, a fictional city government's internal AI assistant, CivicAssist, used across multiple departments. You'll map observations to the full ten-category OWASP 2026 Top 10, implement a real ADR-validity checker, judge honest claims versus overclaims, implement the sandboxing judgment rule as real code, implement a threat-model completeness scorer, critique flawed ADR excerpts, and write a real justification for why a zero-finding red-team pass is a red flag.

Exercise standard Eight tasks total. Five are marked production-gear — a real ADR-validity checker, a real sandboxing-judgment function, a real OWASP-category mapper across all ten categories, a real threat-model completeness scorer, and ADR critique — not just concept recall.
How to run these Download starter.py, fill in every # TODO, then run python3 starter.py to see an automated score report. Compare against solution.py, which scores a perfect 38/38.

1 Map events to the full OWASP 2026 category

Sort six CivicAssist events into the ten OWASP GenAI LLM Top 10 2026 categories.

2 Production-gear Implement an ADR-validity checker

Write is_valid_adr() — a real structural check that an ADR has every required field, a valid defense category, and a non-trivial trade-off statement.

3 Honest claim vs. overclaim/gap

For four described architecture-review statements, decide which reflect sound practice and which contain a real gap.

4 Production-gear Implement the sandboxing-judgment rule

Write is_sandboxing_warranted() — apply this chapter's real rule to a tool's risk profile.

5 Production-gear Map observation to OWASP 2026 category

Given four CivicAssist observations, name the single best-fit OWASP 2026 category.

6 Production-gear Implement a threat-model completeness scorer

Write score_threat_model_completeness() — verify all ten categories are present with a real rationale, not a placeholder.

7 Production-gear Critique ADR excerpts

Given four ADR excerpts, decide which contain a real flaw and which are sound.

8 Written reasoning

Write a real, justified sentence explaining why a self-directed red-team pass reporting zero findings is a red flag, not a compliment.
