# Chapter 1 Project: Preview

This chapter doesn't ship its own project. Module 1's **Level 1
(Guided)** project — threat-model a real, given LLM feature end to end —
needs the full OWASP Top 10 framework from this chapter plus the applied
practice Chapter 2 builds on top of it, so it unlocks once Chapter 2 is
done.

See `index.html` for the full preview page, including what the L1
project will actually ask you to do and why it's worth waiting for.

`starter.py` and `solution.py` in this folder are placeholders that
explain the same thing at the command line — there is no hands-on project
code for this chapter yet. Run either one:

```bash
python3 starter.py
```

Once Chapter 2 ships, this folder is replaced with the real L1 project
scaffold.
